# Código de conduta

Queremos que qualquer pessoa possa contribuir para o Diagnóstico da Bacia do Paranoá com respeito e segurança. Este código se aplica a issues, pull requests, revisões e demais interações no repositório, assim como a espaços em que alguém esteja representando o projeto.

## Como colaborar

- Trate as pessoas com respeito, independentemente de identidade, origem, experiência, formação ou condição.
- Discuta métodos, dados e resultados com base em evidências. Faça críticas específicas e explique as alterações que propõe.
- Acolha perguntas e contribuições, dê crédito pelo trabalho de outras pessoas e respeite a privacidade de quem participa.

Assédio, ameaças, discriminação, ataques pessoais, comentários sexualizados e divulgação de dados pessoais sem autorização são inaceitáveis.

## Como relatar uma violação

Use a opção **Report content** no menu do conteúdo. Quando o GitHub oferecer **Report to repository admins**, você pode encaminhar o relato à manutenção do projeto. O [formulário de denúncia do GitHub](https://support.github.com/contact/report-abuse) também recebe relatos de abuso. Inclua links e contexto suficiente para localizar o ocorrido e preserve dados pessoais fora de issues e comentários públicos. [Instruções do GitHub para denunciar abuso](https://docs.github.com/pt/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

A manutenção pode pedir ajustes, remover conteúdo, limitar interações ou bloquear participantes conforme a gravidade e a recorrência da conduta. Os relatos encaminhados à manutenção devem ser tratados com discrição.
