# Instruções para agentes

Siga o [guia de contribuição](CONTRIBUTING.md) para qualquer alteração neste repositório.

1. Localize ou abra a issue correspondente antes de alterar arquivos.
2. Crie uma branch a partir da `main` e vincule-a à issue. Use o padrão `<tipo>/<resumo>-issue-<numero>` com um dos tipos `doc`, `chore`, `feature` ou `bugfix`.
3. Valide a alteração e abra um PR para a `main` seguindo o [modelo do repositório](.github/pull_request_template.md). Referencie a issue e preencha contexto, comportamento esperado, descrição técnica e validação.
